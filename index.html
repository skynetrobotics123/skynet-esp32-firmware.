Firmware installer for ESP32 DevKit V1 (original ESP32) with OLED 128×64 hardware configuration.

Connect your ESP32 DevKit V1

Connect your board to a computer using a USB data cable.

Use desktop Google Chrome or Microsoft Edge with Web Serial support. Open this installer on a secure HTTPS page.

Installation steps

  1. Check that your board is an original ESP32 DevKit V1, not an ESP32-S3.
  2. Disconnect external peripherals if they interfere with flashing and connect the USB data cable.
  3. Click Flash Firmware, choose the serial port, then follow the prompts.
  4. Keep USB connected until installation is complete.

Warning: Flashing can erase your existing program and saved device data. Test the firmware and verify microphone, amplifier, OLED and GPIO wiring before giving this installer to customers.

Installation interface powered by ESP Web Tools. Skynet Robotics branding here does not change any internal firmware branding.
